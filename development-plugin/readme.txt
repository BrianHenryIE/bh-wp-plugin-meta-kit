A plugin to showcase the BH Plugin Meta Kit library and add test helpers.

== Description ==

This plugin bundles the **BH Plugin Meta Kit** library so its additions to plugins.php can be seen and tested.

* Adds a "View details" link to the plugin's row
* Fills the plugin details modal from this readme

== Frequently Asked Questions ==

= Should I install this on a live site? =

No. It exists for developing and testing the library.
